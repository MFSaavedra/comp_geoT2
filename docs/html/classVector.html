Descripción detallada

template<typename T>
class Vector< T >

Vector en el plano, guardado como el Punto que va del origen a su extremo.

Parámetros de plantilla
TTipo numerico de las componentes.
Nota
La componente z existe para el resultado de productoCruz; las demas operaciones la propagan para no perderla.
