Tipo en que se calcula el producto cruz de coordenadas de tipo T.

Parámetros de plantilla
TTipo de las coordenadas.
Nota
Con T entero es long long, y el resultado es exacto mientras |coordenadas| < 2^30. Con T flotante es double y hay redondeo.

Orientacion del triangulo (a, b, c): signo del producto cruz (b - a) x (c - a).

Parámetros de plantilla
TTipo de las coordenadas.
Parámetros
aPrimer punto.
bSegundo punto.
cPunto a clasificar respecto de la recta a -> b.
Devuelve
1 si c esta a la izquierda de a -> b (giro CCW), -1 si esta a la derecha (giro CW) y 0 si los tres puntos son colineales.
Nota
Promueve a Ancho<T> antes de restar: con T = int, Vector<int> se desborda apenas las coordenadas pasan de 2^15.
