Descripción detallada

template<typename T>
class RandomIncrementalAlgorithm< T >

Cerradura convexa incremental en orden aleatorio, O(n log n) esperado.

Parámetros de plantilla
TTipo de las coordenadas (ver esTipoCoordenada). Con T entero, los calculos son exactos si en cada eje max - min < 2^29 (T de hasta 32 bits) o < 2^61 (T de 64 bits); ver ladoDelRayo.

Parte de un triangulo y agrega los demas puntos en orden aleatorio. Para no buscar en toda la cerradura que aristas ve cada punto nuevo, cada punto que falta por insertar guarda una arista visible: la que cruza el rayo que va desde un punto fijo C (el centroide del triangulo inicial) hasta el punto. Cada arista guarda, a su vez, la "cubeta" con los puntos que la apuntan.

Al insertar un punto q se eliminan las aristas que q ve, se agregan dos (l -> q y q -> r) y solo se reasignan los puntos de las cubetas eliminadas. Un punto que queda dentro de la cerradura se descarta para siempre, porque la cerradura solo crece.

La cerradura se guarda como lista doblemente enlazada en CCW sobre los indices de la copia barajada; una arista se identifica por su vertice de origen v (la arista v -> sig[v]).

int RandomIncrementalAlgorithm< T >::ladoDelRayo ( int v,
int f ) const
inlineprivate

Orientacion de (C, p[v], p[f]), sin calcular C.

Parámetros
vIndice del punto que define el rayo C -> p[v].
fIndice del punto a clasificar.
Devuelve
1 si p[f] esta a la izquierda del rayo, -1 a la derecha, 0 sobre su recta.
Nota
C = suma / 3 no tiene coordenadas enteras; se usa 3p - suma, que es 3 veces el vector C -> p y tiene la misma orientacion. Si en un eje max - min = L, entonces |3p - suma| < 3L y el producto cruz es menor que 18 L^2: cabe en long long si L < 2^29 y en Entero128 si L < 2^61. Usa signoCruz y no orientacion porque los vectores ya estan en W, y orientacion los volveria a promover.
