Descripción detallada

Ejemplo de uso de las estrategias y comparacion rapida entre ellas.

Primero calcula la cerradura de una nube pequena con ambas estrategias. Luego, para cada tipo de coordenadas, cada generador y cada n, mide ambas sobre la misma nube y verifica que las dos cerraduras sean identicas. El experimento completo, con varias instancias por caso, esta en experimento.cpp.
